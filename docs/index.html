ORF-5 — an async 5-in-1 OSINT & reconnaissance toolkit

Point it at a username, a game UID, a URL or an email — it tells you what's public. Built on asyncio + aiohttp, so every probe runs concurrently. Runs on Windows, Zorin OS / any Linux, macOS and Termux on your phone.

⭐ Star this repo if you like it ▶ Run it in GitHub Codespaces

What's inside

01Username Recon

Profile existence across 20 social & gaming networks, judged by HTTP status + body rules. Platforms live in a JSON file — add your own without touching code. python main.py username <handle>

02Game Stats Inspector

Public player data by UID or name — Free Fire MAX and PUBG (official developer API). python main.py gamestats --game freefire --id …

03Metadata Extractor

Open Graph / Twitter Card tags (og:image, og:description, …) from any public page, via BeautifulSoup4. No login, ever.

04Breach Exposure Checker

k-Anonymity SHA-1 range queries against HaveIBeenPwned — only a 5-character hash prefix ever leaves your machine.

05Dual Interface

A full argparse CLI and an asynchronous Telegram bot (aiogram 3) driven by the same engine. One codebase, two front doors.

⚡Honest results

Sites that reject bots aren't faked — they're reported as BLOCKED, so you always know the difference between "no profile" and "couldn't tell".
